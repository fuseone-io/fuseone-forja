# ADRs da Forja

Registros de decisão de arquitetura. Um ADR nasce como `9999-<slug>.md` e é
renomeado para o número da PR que o introduz, logo após a PR ser aberta.

| ADR | Título | Status |
|---|---|---|
| [0027](0027-repositorio-piloto.md) | Repositório piloto e mantenedor da fase 0 (default provisório) | proposto — ratificação pendente |
